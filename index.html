品牌简介

自由鲸(freewhale)把稳定访问、可预期延迟和清晰操作路径放在首位。服务形态是机场订阅：你按月或按年获取流量与设备额度，在常用客户端中导入订阅即可切换节点。线路覆盖普通节点池与 IPLC 专线，用于网页加速、流媒体解锁、远程办公和游戏优化。

我们在官网上公开基础版、旗舰版与团队版的流量、设备数与能力边界，避免把「全功能」写进每一个套餐。新用户建议先看配置流程，再按设备数量和流量选择方案，最后到客户端下载区获取对应系统的客户端。

自由鲸官网同时承担说明文档角色：节点用途、导入方式、故障排查都写在同一页面，减少在多个入口之间来回查找。

为何先看配置流程

多数连接失败并非线路本身，而是订阅未更新、客户端内核过旧或选错协议。自由鲸把配置流程放在页面中部：选套餐、复制订阅、下载客户端、导入并更新、按场景选节点。按顺序操作，可在数分钟内完成首次连接。

旗舰版与团队版额外提供工单或客户经理通道，适合把加速器当作日常办公基础设施的用户。基础版足以覆盖浏览、轻度流媒体与三台设备同时在线。

使用场景

远程办公与云协作

视频会议、代码仓库、设计稿同步和云桌面需要连续会话。建议使用旗舰版 IPLC 或团队版 VIP 节点，并在客户端为办公域名设置分流，避免把全部国内流量绕行海外。

资料查阅与公开课

学术镜像、文档站点与公开课程平台对延迟不极端敏感，但对可用性要求高。基础版普通线路节点池即可覆盖多数查阅场景；若需长时间下载，预留流量或选择更高额度套餐。

国际流媒体

基础版面向常见平台的基础解锁；旗舰版强调全节点原生解锁，减少因共享出口导致的播放中断。播放前在客户端更新订阅，选择标注流媒体的区域节点。

游戏加速

对延迟抖动敏感的对战与登录，优先走 IPLC 专线。将游戏进程或端口加入代理规则，大厅与下载可分流。团队版高带宽节点适合多人同时在线。

差旅与多设备

手机、笔记本与平板同时在线时，按套餐设备数规划。差旅切换网络后，先更新订阅再连接；若公司网络限制 UDP，改用客户端中的 TCP 或兼容协议。

配置流程与操作说明

自由鲸的上手路径固定为五步。请按顺序执行，不要在未导入订阅时反复切换节点。

第一步：在官网确认套餐

对照设备数、月流量和是否需要 IPLC / 原生流媒体。个人轻度使用选基础版；常看流媒体或需要游戏加速选旗舰版；工作室或多终端选团队版。年付适合确定会连续使用十个月以上的用户。

第二步：完成订阅并复制链接

在用户中心找到「订阅地址」或「Clash / 通用订阅」。复制完整 URL，不要手动删减 token。若提供单独的二维码，仅在手机客户端内扫描，避免把订阅发到公开聊天。

第三步：下载对应客户端

Windows 与 macOS 使用桌面客户端或 Clash 系内核；Android 使用兼容订阅的加速器客户端；iOS 使用商店内可导入订阅的工具。到本页客户端下载选择系统，安装后不要并行开启多个代理内核，以免端口冲突。

第四步：导入订阅并更新节点

打开客户端的「配置 / 订阅 / Profiles」，粘贴链接并命名为「自由鲸」。执行一次「更新」。成功后应看到香港、日本、新加坡、美国等分组，以及旗舰与团队套餐中的 IPLC 或 VIP 列表。导入失败时检查是否复制了空格或使用了过期链接。

第五步：按场景选择节点并连接

日常浏览选普通线路负载较低的节点；流媒体选对应地区且标注解锁的节点；游戏与会议选 IPLC。连接后访问状态页确认出口 IP 与延迟。若网页能开但应用不行，检查是否开启了系统代理或 TUN 模式。

日常维护

每周更新一次订阅。客户端提示内核过旧时再升级，不必频繁更换软件。公司网络异常时，尝试切换端口或协议，而不是连续更换十几个节点。流量将尽时在官网升级套餐，避免中断后才处理。

常见问题

自由鲸是什么？和普通加速器有何不同？

自由鲸(freewhale)是提供机场订阅的 VPN 网络加速服务。你购买的是按月流量、设备数和线路能力，而不是一次性破解软件。官网强调配置流程：订阅导入客户端后才能稳定使用。与只给一个节点文件的工具相比，订阅可以持续更新线路，不必每次手动替换配置。

如何完成机场订阅并在客户端里用起来？

先选择基础版、旗舰版或团队版，在用户中心复制订阅地址，下载对应系统客户端，于配置页粘贴链接并更新，再按场景连接普通节点或 IPLC。五步顺序见上方配置流程。不要把订阅链接发到公开群组，泄露后需要在官网重置。

支持哪些设备？设备同时在线不够用怎么办？

常见桌面与移动系统均可，只要客户端能导入通用订阅。基础版 3 台、旗舰版 5 台、团队版 20 台同时在线。超过额度时，关掉长期挂机但不使用的终端，或升级套餐。同一账号在多台设备导入订阅是允许的，限制的是并发连接数。

基础版、旗舰版和团队版该怎么选？

以流量和线路类型为主：每月约 100GB、三台设备、基础流媒体选基础版；需要原生解锁、游戏 IPLC 和优先工单选旗舰版；多人共用、定制路由和专属客户经理选团队版。年付适合长期使用。不确定时可先按月开通，确认节点与客户端习惯后再改年付。

连上以后网页正常但流媒体或游戏不行？

先更新订阅，改用标注解锁或 IPLC 的节点，并确认客户端处于规则模式而非全局把国内游戏平台也送出海外。流媒体避免频繁切换地区。游戏将进程加入代理列表，并关闭其他占用网卡的加速软件。仍失败时通过旗舰优先工单或团队客户经理提供客户端日志时间点。

客户端应从哪里下载？能否只使用网页版？

请使用本页客户端下载区给出的系统入口。网页无法完整替代本地内核，尤其是 UDP 游戏与系统级代理。iOS 需在系统允许的客户端中导入订阅。任何要求关闭安全软件或替换系统证书的第三方包都不要作为官方下载来源。
